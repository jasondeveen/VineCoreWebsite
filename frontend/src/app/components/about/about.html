About

Independent, hands-on, project-based.

VineCore is a one-person consultancy. I'm an industrial engineer (Electronics-ICT) with four years as a software developer at ArcelorMittal, now working independently.

My aim is to build software that makes sense. With AI making it easy to generate more code than anyone can review, I'd rather keep it small, focused, and correct — code you can still reason about a year later and trust in production.

I work hands-on and project-based, on embedded software and the software around it. I like short lines with the engineers who build the product, and I'm available for project work and interim capacity.
